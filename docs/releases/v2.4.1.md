## 变化

- 修复“我的 App”页面的 UIKit 复用断言、第三方 IPA 异常元数据崩溃、Apple Watch companion/`arm64_32` 签名崩溃和 Server 终态响应竞争。
- 增加有界、脱敏的操作恢复日志、安装阶段与百分比，并在检测到 App Extensions 时让用户选择推荐剔除或保留签名。
- 完整收敛简体中文、浅色/深色语义色、AltForge 仓库入口与主题色即时刷新。
- 优化浏览空状态与“我的 App”有效期文案，避免空分区标题和中文残句。
- 应用图标扩展为九款，新增四款扁平风格及钛金属、光学玻璃、陶瓷珐琅三款材质风格；切换时使用行内进度和局部更新。
- AltSign 在重签名时识别并保留 HealthKit entitlement/capability 映射。

## 兼容性与升级

- 保持 Classic 形态、现有 bundle identifier、Core Data schema 与 Server Protocol，不需要数据迁移。
- 可直接通过 AltForge Server 覆盖安装 `2.4.0`；删除 App 会同时删除其本地数据，因此不建议为升级先卸载。

## 已知限制

- IPA 由发布流程无签名构建，安装时由 AltForge Server 针对用户和设备签名。
- macOS DMG 当前使用 ad-hoc 签名，未 Developer ID 签名或 notarize；Windows ZIP 未代码签名。
- Windows 仍依赖 Apple 官网版 iTunes/iCloud。
- 第三方 IPA、扩展保留/剔除、HealthKit、USB/Wi-Fi 刷新和九款图标逐一切换仍需要维护者在真实设备上完成最终验收；自动化构建不能替代这些设备场景。

## 回滚

若真实设备出现阻断问题，可覆盖安装 `v2.4.0` 的 IPA；版本回退不会迁移或删除数据库，但新版本产生的诊断 journal 会被旧版本忽略。AltSign 回滚必须同时恢复 nested commit 与主仓库 gitlink。
