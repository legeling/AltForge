## 更新内容

- 选择 IPA 后可检查应用名称、包名、版本与扩展数量。可以保持原样直接安装，也可以在签名和安装前分别修改显示名称与包名；原始 IPA 不会被改写。
- 已安装且有缓存的托管应用可以从“我的应用”修改显示名称，使用原包名重新安装。修改包名会产生新的安装身份，不是原位重命名；登录、共享数据、通知等能力可能受原包名绑定影响。
- 安装进度现在属于“我的应用”列表内容，会随页面滚动。返回前台时，若本地安装记录尚未出现，新版 Server 可以查询设备实际安装的包名并恢复托管记录；不能仅凭 App ID 注册判定安装成功。
- iOS、macOS 和 Windows 产品版本统一为 2.5.1。

## 验证与边界

- 标签 CI 的 iOS XCTest、iOS/macOS 打包检查、Windows 构建和发布校验全部通过。分支三端预检也通过：[run 35828141331](https://github.com/legeling/AltForge/actions/runs/35828141331)。本机 macOS AltServer Debug 构建、编辑器合成 fixture、版本/仓库契约与隐私检查通过；本机没有 iOS Simulator runtime，因此 iOS XCTest 使用 CI 环境执行。
- 从 Draft 下载全部九个产物后，`SHA256SUMS.txt` 所列八项均重新计算并通过；下载的 IPA 与 `apps.json` 隐私权限声明检查通过，覆盖主应用与扩展两个 bundle。`apps.json` 使用固定的 v2.5.1 IPA URL 和 build 30。
- `releases/latest` 已确认指向非 Draft、非预发布的 v2.5.1；公开的 IPA、macOS DMG、Windows ZIP、`apps.json` 和校验清单下载链接均返回 HTTP 200。
- 真实设备的并行安装、改名后刷新，以及锁屏/后台安装后记录恢复尚未验收，由上述两个 issue 跟踪。iOS 后台任务不能保证锁屏或强制退出后无限期运行；恢复逻辑在应用返回前台时核对实际结果。
- IPA 为未签名包，仍须由服务端为设备签名安装；macOS DMG 仅有 ad-hoc 完整性签名，未 Developer ID 签名或公证；Windows 二进制未签名。

## 更新与回退

先更新电脑端 AltForge Server，再通过现有安装流程更新手机 AltForge，才能使用设备安装记录查询。旧 Server 或设备离线时不会凭空补记安装，待设备与 Server 可用后再返回“我的应用”核对。

本版没有数据库迁移。跨进程协议增加了设备安装包名查询；旧 Server 不提供该查询，旧版本仍可安装。回退到旧客户端/Server 会失去本版编辑与设备核对能力，已更名或改包名的应用不会自动改回。
