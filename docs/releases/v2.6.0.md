## 更新内容

- macOS 菜单提供独立常显的“安装 IPA”，在 Apple ID 认证前显示名称、包标识符、版本、扩展与可读取的图标，再选择直接安装或编辑安装。
- Mac 可选择 PNG/JPEG 文件、拖动和缩放裁切图标；iOS 导入 IPA 时可从照片选择并用系统编辑器裁切。两端在临时 `.app` 中独立修改名称、包标识符和图标，原 IPA 不变。自选图标写入 iPhone/iPad 主图标引用及所需尺寸变体。
- 安装进度显示所选应用名称及可读取图标。iOS、macOS、Windows 产品版本同步为 2.6.0。

## 验证与边界

- 本机 macOS Debug build、原生非正方形裁切/缩放 fixture、iOS SDK 共享编辑器类型检查、静态契约、本地化和发布隐私检查通过。本机缺少 iOS 26.5 平台，因此未在本机运行 iOS target build 或模拟器测试。
- 分支三端预检 [run 35985608497](https://github.com/legeling/AltForge/actions/runs/35985608497) 与标签发布 [run 35987685997](https://github.com/legeling/AltForge/actions/runs/35987685997) 均通过。标签 CI 覆盖 iOS Simulator 定向 XCTest（含图标临时副本测试）、unsigned IPA、macOS Universal DMG、原生图标 fixture、Windows ZIP 和 source/隐私发布检查。
- 从 Draft 下载全部九个附件，`SHA256SUMS.txt` 中列出的八项均重新计算通过。下载的 IPA/DMG 另经 `verify_apple_release_artifacts.sh` 核对包结构、bundle identity、版本/build 32、DMG Applications 链接、macOS Universal 架构、deep ad-hoc 签名和非 Developer ID 策略；隐私声明覆盖主 App 和扩展两个 bundle。Windows ZIP 含 AltServer.exe；Windows 构建和资源版本契约在 CI 通过，未在本机运行 Windows 程序或设备安装。
- `releases/latest` 与公开 `apps.json` 已确认指向 v2.6.0/build 32；公开 IPA、DMG、Windows ZIP 与 checksum 链接均返回 HTTP 200。`apps.json` 的当前 IPA URL 固定到 v2.6.0，且保留十个版本。
- 真机并排安装、实际主屏幕图标、刷新后的图标与身份、锁屏/后台安装后记录恢复仍待 `ISSUE-20260923-001` 和 `ISSUE-20260905-003` 验收，不能从模拟器和包结构推断成功。
- Mac 图片文件限 PNG/JPEG、每边 180–4096 像素、20 MiB；iOS 照片经系统裁切后统一生成 PNG。改包标识符可能影响第三方 App 的登录、共享数据、Keychain 与通知。IPA 未签名，需通过 Server 为设备签名安装；macOS DMG 未 Developer ID 签名或公证，Windows 二进制未签名。

## 更新与回退

先更新电脑端 AltForge Server，再更新手机端 AltForge。旧 Server 缺少已有的设备结果查询能力；仅更新手机端不足以获得完整的安装恢复体验。本版没有数据库或跨进程协议迁移。回退旧版不会自动撤销已安装的改名、改包名或自定义图标应用；原始 IPA 未被修改，需要重新安装时可重新导入。
