## 变化

- iOS 客户端和 macOS AltForge Server 提供简体中文资源与语言切换。
- 对外产品名称、更新检查、支持和下载入口收敛到 AltForge 仓库。
- macOS 菜单、About 和设置窗口完成重新整理，设备菜单显示 USB/Wi-Fi 连接类型。
- 修复重签后没有可用 App Group container 时的 iOS 首次启动失败，并禁止数据库或 Apps 缓存迁移到相同路径。
- macOS 安装增加可见阶段、传输量、速度、线路选择、单设备去重与镜像完整性校验；Classic AltSign 恢复 Apple 认证所需的 crypto 路径。
- 同一 tag 产出 unsigned IPA、Universal macOS DMG、Windows ZIP 与仓库自主维护的 source/configuration metadata。

- GitHub hosted `prepare`、`apple`、`windows` 和 `publish` jobs 全部成功；prepare 递归检出 submodule 后执行 release policy contract。
- Apple job 完成 iOS source identity tests、unsigned device Release build、Universal macOS Release build、IPA/DMG 打包与 artifact verifier。

## 限制与回滚

- IPA 未签名，安装时由 AltForge Server 针对用户和设备签名。
- macOS DMG 未使用 Developer ID 签名或 notarize；Windows ZIP 未使用代码签名。
- Windows 运行仍依赖 Apple 官网版 iTunes/iCloud。Apple 和 Windows 真实设备安装、刷新、USB 和 Wi-Fi smoke test 尚未执行。
- 已安装原始 IPA 的用户应通过 AltForge Server 覆盖安装重新发行版本；删除 App 会同时删除本地数据。
