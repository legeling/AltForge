## 实际验证

- GitHub hosted `prepare`、`apple`、`windows` 和 `publish` jobs 全部成功。
- Apple job 完成 iOS source identity tests、unsigned device Release build、Universal macOS Release build、IPA/DMG 打包与 artifact verifier。

- 公开发布后重新下载九项产物；`shasum -a 256 -c` 全部通过，GitHub 记录的 asset digest 与校验清单一致。
- 重新下载的 IPA/DMG 通过结构、bundle identity、`2.4.0 (8)`、Universal architecture 与 non-Developer-ID policy 检查；Windows ZIP 无路径穿越且包含必需 runtime 与许可证。
- 五个 JSON asset 均可解析，`apps.json` 的版本、build number 和 tag-fixed IPA URL 通过独立检查。

## 限制与回滚

- IPA 未签名，安装时由 AltForge Server 针对用户和设备签名。
- macOS DMG 未使用 Developer ID 签名或 notarize；Windows ZIP 未使用代码签名。
- Windows 运行仍依赖 Apple 官网版 iTunes/iCloud。Apple 和 Windows 真实设备安装、刷新、USB 和 Wi-Fi smoke test 尚未执行。
- 发布前为修复 hosted CI 暴露的问题，未公开的 `v2.4.0` tag 对象曾重建；期间没有 GitHub Release 或已公开产物。本记录中的 commit 是唯一正式发布对象。
- `v2.4.0` 公开后不覆盖 tag 或同名产物；如需修复，发布新的 patch 版本并在说明中标注回退建议。
