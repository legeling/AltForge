# AltForge v2.4.3

- 发布日期：2026-09-04（Asia/Shanghai）
- Tag：`v2.4.3`
- Commit：`1f7099737205581b254dc894cc305a1b2317b1b1`
- Build number：`21`
- Workflow：[GitHub Actions run 33863304381](https://github.com/legeling/AltForge/actions/runs/33863304381)
- Release：[AltForge v2.4.3](https://github.com/legeling/AltForge/releases/tag/v2.4.3)

## 变化

- macOS AltForge Server 检查到新版本后，主操作由“打开发布页面”改为“下载更新”。
- 新增独立下载进度窗口，显示实际字节和百分比，支持取消并防止重复操作创建并发下载。
- 只接受当前 tag 下的本仓 GitHub DMG，写入“下载”文件夹前校验 GitHub API 发布的文件大小和 SHA-256。
- 下载并校验完成后自动打开 DMG，让 macOS 直接显示安装窗口；失败时提供明确原因、重试、访达定位或 Release 兜底。
- iOS AltForge、macOS AltForge Server 与 Windows AltForge Server 产品版本统一为 `2.4.3`。

## 兼容性与升级

- 保持 Classic 形态、现有 bundle identifier、Core Data schema 与 Server Protocol，不需要数据迁移。
- 可直接覆盖安装 `2.4.2`；不要先删除 iOS App，以免同时删除本地数据。
- `2.4.1` 和 `2.4.2` 的旧更新弹窗仍需通过发布页面下载本版；从 `2.4.3` 开始，后续新版可以在 AltForge Server 内直接下载。

## 已知限制

- macOS DMG 当前使用 ad-hoc 签名，尚未 Developer ID 签名或 notarize，因此本版自动下载并打开安装器，但不会静默覆盖正在运行的 `/Applications/AltForge Server.app`。
- 自动化覆盖代码、Release 构建、真实 DMG size/SHA-256 和产物结构；低版本 GUI 的下载、取消、失败重试及自动挂载矩阵尚未人工操作验收。
- IPA 由发布流程无签名构建，Windows ZIP 未代码签名。
