# AltForge v2.4.6

- Status: Release preparation; not yet published
- Version: 2.4.6 for iOS AltForge, macOS AltForge Server and Windows AltForge Server
- Change: CHG-20260905-003; device acceptance remains tracked by ISSUE-20260905-003
- Release: https://github.com/legeling/AltForge/releases/tag/v2.4.6
- AltSign: unchanged from v2.4.5 (`9b06df71234804204bbbcb65ed135edd0d15b8cb`)

## 更新内容

- 修复后台安装完成后可能遗漏管理记录的问题：安装前保存恢复信息，收到成功回执立即保存记录；回到前台后有限次数核对系统登记，确认已安装后补回“我的 App”。
- 不再因暂时查不到系统登记就自动删除应用记录与刷新缓存；恢复过程避开仍在运行的安装任务，并避免重复记录。
- IPA 导入显示安装阶段、进度和耗时，保留完成或错误结果。安装阶段断线、超时或取消时显示“安装结果待确认”，不直接断言设备安装失败。
- 手动安装和刷新期间防止自动锁屏，结束后恢复原设置；这不绕过手动锁屏或 iOS 后台运行限制。
- 统一安装、认证、设置及通用控件的主题色，改善大字体和导航安全区域布局；错误和到期提醒仍保留语义警示色。
- iOS App 与 macOS、Windows 服务端同步版本号；桌面认证逻辑沿用 v2.4.5，本次没有新的 Windows 登录修复。

## 验证与边界

- 本地 28 项不同 XCTest 已通过分批验证，iOS 模拟器构建通过。覆盖安装记录恢复、延迟登记、前后台切换、重试上限、并发状态读取、去重、保存失败回滚、进度、常亮与主题布局。
- 用户要求先发布再做真机测试。真实后台安装、恢复记录后的再次刷新及完整设备视觉矩阵尚未验收，不能将模拟器结果描述为真机问题已彻底解决。
- 标签 CI 将重新执行全部 28 项用例、iOS/macOS/Windows 构建和打包验证。公开发布前必须下载 Draft 资产并核对完整性；实际结果在发布后补记。
- IPA 未签名，需要服务端签名安装。macOS 使用 ad-hoc 完整性签名，未 Developer ID 签名或公证；Windows 二进制未签名。

## 升级与回滚

先更新电脑上的 AltForge Server，再覆盖更新手机上的 AltForge，保留现有应用和数据。macOS 更新器下载并校验 DMG 后打开安装窗口，不会静默替换正在运行的程序。

手机仍使用旧版且应用内更新无法通过认证时，请从新版电脑服务端覆盖安装 AltForge，不要先卸载手机端。

旧版本已经遗漏的应用若没有留下恢复信息，无法仅凭 App ID 自动重建。保留手机上的应用，使用原 Apple ID/team 重新导入原 IPA，不要先卸载。

没有 Core Data schema 迁移。v2.4.5 安装包仍可用于回滚，但旧版不识别新增恢复记录且仍含旧的清理逻辑，可能再次丢失管理记录，不建议为排查本问题回退。
